## SQL源码漏洞：不安全的参数模式

这个漏洞发生在当`mode`变量没有被正确设置时。在这种情况下，默认的参数模式是`IN`，但是通过明确定义它，可以使代码更容易阅读。

**漏洞示例**：

```sql
CREATE OR REPLACE PROCEDURE myproc('hello') AS
BEGIN
  NULL;
END;
```

在上述示例中，`myproc`进程使用了一个明文参数`'hello'`，这可能导致 SQL 注入攻击。虽然这里没有发生实际的注入攻击，但是这种情况可能吸引黑客进行进一步的攻击。

为了防止这种漏洞，请确保在使用`myproc`进程之前正确设置`mode`参数。
