## SQL 查询优化实践与问题分析

### 1. 问题描述

在 SQL 查询中，有时候我们需要对某些字段进行比较，例如判断某个值是否为真或假。为了提高代码的可读性，我们希望移除这些 literal 布尔值，而是使用更加简洁的逻辑运算符。然而，如果不正确地处理这个问题，可能会导致 SQL 查询执行效率降低。

### 2. 非合规代码示例

在一些 SQL 查询中，我们可能看到如下代码：

```sql
if var = true then ...
if var = false then ...
```

在这里，我们使用了 `=` 作为比较运算符。这种写法是不合规的，因为它直接将字面值与比较运算符混合在一起，这可能导致解析器无法正确识别 `var` 的实际类型。

### 3. 合规解决方案

为了改进这种情况，我们可以采用更合规的方法来编写 SQL 查询，比如使用逻辑运算符 `then` 和 `else`：

```sql
if var then ...
if not var then ...
```

在这个解决方案中，我们将原比较语句 `var = true` 和 `var = false` 分别改写为 `var then ...` 和 `not var then ...`。这样，我们就避免了将字面值与比较运算符混合在一起的问题，从而提高了 SQL 查询的解析性能。
