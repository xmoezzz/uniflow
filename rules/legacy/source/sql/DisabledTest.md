# SQL代码段漏洞描述

## 漏洞名称：忽略未注释的禁用测试用例

当一个测试由于例如基础架构问题而失败时，您可能暂时希望忽略它。但是，如果没有某种表示测试为什么被禁用的注释，那么这个测试可能永远无法激活。

此规则对于每个没有注释说明其被禁用的禁用测试引发一个问题。

不合规代码示例
--------------

```sql
-- %test(my test)
-- %disabled
procedure test;
```

合规解决方案
--------------

```sql
-- %test(my test)
procedure test;
```

例外
----

该规则如果在`%disabled`注释中存在注释则不会引发问题。
