# 重复的条件语句通常是错误

重复的条件语句在比较操作中几乎总是一个错误。这可以是一个复制/粘贴错误，从而导致一个错误，或者仅仅是浪费的代码，应该简化。

不合规代码示例
--------------

```

IF (x = 1) AND (x = 1) THEN ...

```

## 解析

上述代码存在重复条件语句的问题。在 `AND` 运算符中，两个相同的条件会被连续执行两次。这可能导致逻辑错误，特别是在复杂的条件和表达式中。

修复建议
-------

消除重复的条件语句，确保每个条件只被执行一次。可以使用 `OR` 运算符来组合多个条件，而不是使用 `AND` 运算符。
