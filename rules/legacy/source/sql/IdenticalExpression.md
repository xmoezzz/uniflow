# 漏洞名称：双侧操作符使用同一值

## 描述

在 SQL 中，对 Operator 的两边使用相同的值往往是一个错误。这可能是由于复制粘贴错误导致的错误，也可能是简单的代码冗余。

## 非合规代码示例

```sql
if a = a then ...
```

## 漏洞原理

在这个例子中，`=` 是一个比较运算符，用于比较两个值是否相等。如果 `a` 的值为 `a`，那么条件表达式的结果将为真。在这种情况下，程序将继续执行后续的代码块。

## 漏洞影响

这个漏洞可能会导致 unexpected 结果，因为它使得 SQL 查询不正确地比较了两个变量。这可能会导致错误，例如在某些情况下，它可能会返回一个不期望的结果。

## 修复建议

要修复这个问题，可以简化代码，避免在比较运算符的两边使用相同的值。可以使用其他方法来检查变量，而不是直接比较它们。
